# Leçons apprises

- Ne jamais utiliser GitHub (ni `gh`, ni dépôt, ni issues) : le suivi se fait dans `docs/backlog.md` et le dépôt distant est le GitLab de l'université, géré par l'utilisateur.
- Ne jamais vider, supprimer ou recréer la base de développement (ni ses volumes) sans l'accord explicite de l'utilisateur.
